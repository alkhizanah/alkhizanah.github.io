About

A collective of developers building practical tools, shared infrastructure, and open documentation for reliable software delivery.

Our mission

We believe in building software that matters. Our focus is on creating tools and solutions that solve real problems and make developers' lives easier.

What we value

Purpose-driven
Every project addresses real-world challenges with practical solutions.
Open source
Transparent development with community collaboration at the core.
Quality first
Well-documented, tested, and maintainable code as standard.
Collaborative
Building together through shared knowledge and mutual respect.

How to contribute

  1. Start a discussion. Open an issue before implementing large changes to align on approach.
  2. Keep it focused. Submit focused pull requests with clear documentation updates.
  3. Follow standards. Use consistent coding styles and write meaningful commit messages.
  4. Stay engaged. Respond to feedback promptly and keep all communication respectful.

Get in touch

Interested in collaborating or have questions about our projects? Open an issue in any repository or visit the Al Khizanah GitHub organization.
